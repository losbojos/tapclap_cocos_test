# tapclap_cocos_test

Тестовое задание. Прототип головоломки в жанре **Blast**: клик по группе из ≥ N (N=4) соседних тайлов одного цвета сжигает её, столбцы ссыпаются вниз, пустоты заполняются сверху. Цель — набрать нужное число очков за лимит ходов.



**Стек:** TypeScript, [Cocos Creator 2.4.15](https://www.cocos.com/) (2D, без физического движка).

## Демо

[Игра в браузере](https://losbojos.github.io/tapclap_cocos_test/)

## Запуск

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/losbojos/tapclap_cocos_test.git
   cd tapclap_cocos_test
   ```

2. Открыть папку проекта в **Cocos Creator 2.4.x** (*File → Open Project*).

3. Открыть сцену `assets/Scene/main.fire` и нажать **Play** (превью в браузере).

4. Сборка под Web: *Project → Build* → платформа **Web Mobile** или **Web Desktop**.

**Требования:** Cocos Creator **2.4.15** (версия указана в `project.json`). Другие 2.4.x обычно совместимы, но не гарантированы.

## Управление

| Действие | Как |
|----------|-----|
| Сжигание группы | Клик по тайлу в группе ≥4 одного цвета |
| Бомба | Кнопка бомбы → клик по клетке (взрыв в радиусе) |
| Телепорт | Кнопка телепорта → перетащить тайл на другой (свап) |
| Отмена бустера | Повторный клик по той же кнопке бустера |
| Автоматически | Перемешивание поля при отсутствии допустимых ходов |

Бустеры тратят **заряд**, но **не тратят ход**.

## Реализовано

**Основное**

- [x] Сжигание группы, падение и дозаполнение поля
- [x] Счётчик очков и оставшихся ходов (HUD)
- [x] Победа при достижении цели по очкам / поражение при заврешении доступных ходов или отсутствии групп тайлов после 3-х перемешиваний поля

**Дополнительно**

- [x] Перемешивание при отсутствии ходов (до 3 раз подряд, затем поражение)
- [x] Бустер «бомба»
- [x] Бустер «телепорт» (drag-and-drop свап двух тайлов)

**Не реализовано (дополнительно и на развитие)**

- [ ] Супер-тайл при большой группе
- [ ] Автоматический перерасчет размеров\расположения игрового поля от настроек и размеров экрана
- [ ] Анимации завершения игры
- [ ] Рестарт новой партии
- [ ] Звуки


## Архитектура

Разделение по слоям (упрощённый MVC под Cocos):

```
GameController     — оркестрация: ввод, анимации, связь model и view
Board              — сетка, группы, сжигание, свап, перемешивание
GameSession        — сессия игры (партия): Счёт, ходы, бустеры, взведение счёт, ходы, статус
BoosterInventory   — счётчики бустеров
Tile               — плитка (тайл): тип, цвет
BoardView          — отрисовка тайлов, клики, визуальные эффекты 
HudView            — отрисовка индикаторов: счёт, цель, оставшиеся ходы, результат игры.
BoostersView       — Отрисовка бустеров
```

Конфигурация баланса, размера поля, и др. — `assets/Script/GameConfig.ts`.  
Параметры доски (размер клетки, отступы) — компонент **BoardView** на узле `boardNode` в сцене.

## Структура сцены `main`

| Узел | Компоненты |
|------|------------|
| `Canvas` | Canvas, Widget, **GameController** |
| `background` | Sprite, Widget, **AppBackgroundView** |
| `hudNode` | **HudView** (ходы, очки) |
| `boardNode` | **BoardView**, дочерние `bg`, `tilesLayer` |
| `boostersNode` | **BoostersView** |

## Настройки по умолчанию (`GameConfig`)

| Параметр | Значение |
|----------|----------|
| Поле | 10×11 |
| Мин. размер группы | 4 |
| Цель по очкам | 100 |
| Лимит ходов | 25 |
| Радиус бомбы | 2 (клетки) |
| Заряды бомбы / телепорта | 3 / 5 (`BoosterConfig`) |
