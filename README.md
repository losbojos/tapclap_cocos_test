# tapclap_cocos_test - Тестовое задание Tapclap, 2026.

Прототип головоломки в жанре **Blast**. Клик по группе соседних тайлов одного цвета сжигает её; остальные падают вниз, пустоты заполняются сверху. Цель — набрать заданное число очков за ограниченное число ходов.

**Стек:** TypeScript, Cocos Creator 2.4.x (без физического движка).

## Запуск

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/losbojos/tapclap_cocos_test.git
   cd tapclap_cocos_test
   ```

2. Открыть проект в **Cocos Creator 2.4.x** (*File → Open Project*).

3. Запустить главную сцену в редакторе (**Play**) или собрать Web Mobile / Web Desktop (*Project → Build*).

## Реализовано

**Основное**

- [ ] Сжигание группы тайлов, падение и дозаполнение поля
- [ ] Счётчик ходов и очков
- [ ] Выигрыш / проигрыш

**Дополнительно** *(по мере готовности)*

- [ ] Перемешивание при отсутствии ходов
- [ ] Бустеры (бомба, телепорт, супер-тайл)

## Примечания

Правила подсчёта очков, лимиты ходов/очков и прочие детали, не зафиксированные в ТЗ, выбраны в рамках прототипа. Логика отделена от отображения там, где это уместно.
